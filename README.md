# 南一版六年級上學期社會科互動網站｜1-1 第一版

這是可離線開啟的靜態網站，教材來源為 D:\01.AI\80.六上社會｜歷史探索地圖\1-1日本的統治措施.pdf，並以同資料夾內的南一六上社會_1-1_Obsidian 筆記包核對事件、人物與關聯。第一版只處理 1-1；1-2、1-3、2-1、2-2 尚未提供內容，網站僅顯示「準備中」。

## 使用
解壓縮後直接開啟 index.html。網站沒有外部套件，手機、平板與電腦皆可使用。

## 免費發布到 GitHub Pages
1. 登入 GitHub，按 New repository，建立公開 Public 儲存庫。
2. 在儲存庫按 Add file、Upload files，上傳 index.html、styles.css、app.js、README.md。
3. 按 Commit changes。
4. 開啟 Settings、Pages。
5. Source 選 Deploy from a branch；Branch 選 main、資料夾選 root，按 Save。
6. 等待部署完成，Pages 頁面會出現網址，通常是 https://帳號.github.io/儲存庫名稱/。
7. 用手機無痕視窗測試網址，再分享給學生與家長。

## Cloudflare Pages 替代方案
在 Cloudflare Dashboard 選 Workers and Pages、Create application、Pages、Connect to Git，連接 GitHub 儲存庫；Framework preset 選 None，Build command 留空，Build output directory 填 root，再按 Save and Deploy。
